# Public exclusions

The candidate ZIP contains only the public repository tree. It excludes private contract directories, agent/execution logs, environment folders, workstation paths, credentials, caches, build intermediates, the multi-gigabyte full-score/cumulative arrays, duplicate exported PNG suites, and private research artifacts. No HOLDOUT material is included or accessed.

Compact exact summaries, histograms, coefficient grids and original synthetic/public datasets are included with provenance. Historical benchmark fixtures are DEVELOPMENT/synthetic material already selected for the public candidate. Text describing unsupported estimators is retained as limitations documentation; the estimators are not installed. The separate shell-recovery experiment is documented, not added to the inference API.

The outer review folder holds maintainer-only validation logs and reports. It is not the ZIP input. Remote publication requires human approval.
